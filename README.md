## 📱 Termux Hızlı Kurulum (Android)

Termux terminalinde tek satırla hızlıca kurmak ve çalıştırmak için:

```bash
pkg update -y && pkg install python git -y && git clone https://github.com/leny-git/VOID-EX.git && cd VOID-EX && python void-ex.py
```

### Adım Adım Termux Kurulumu:

1. **Paketleri güncelleyin ve gerekli araçları yükleyin:**
   ```bash
   pkg update && pkg upgrade -y
   pkg install python git -y
   ```

2. **Repoyu klonlayın:**
   ```bash
   git clone https://github.com/leny-git/VOID-EX.git
   ```

3. **Klasöre girin ve çalıştırın:**
   ```bash
   cd VOID-EX
   python void-ex.py
   ```

## 💻 Linux / WSL2 Kurulumu (Ubuntu)

1. **Bağımlılıkları yükleyin:**
   ```bash
   sudo apt update && sudo apt install python3 python3-pip git -y
   ```

2. **Repoyu klonlayıp çalıştırın:**
   ```bash
   git clone https://github.com/leny-git/VOID-EX.git
   cd VOID-EX
   python3 void-ex.py
   ```
